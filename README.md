# gpu-worker

Однократная настройка нового Windows-ПК как GPU-воркера (доступ по Tailscale + SSH).

## Одна команда

PowerShell **от администратора**:

```powershell
irm https://raw.githubusercontent.com/azama2t/gpu-worker/main/setup_once.ps1 | iex
```

Что делает: ставит Tailscale (один раз откроется вход), включает OpenSSH Server с автозапуском и правилом брандмауэра, добавляет публичный ключ главного ПК, выключает сон, ставит план «Высокая производительность». В конце печатает IP в Tailscale, имя ПК и пользователя — их нужно прислать оператору.

Дальше всё (окружение, данные, раннер обучения как скрытая задача) разворачивается по SSH с главного ПК. Секретов в репозитории нет: только публичный ключ.
